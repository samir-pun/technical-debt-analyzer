What happens to your code

Four stages, each one explainable.

Static analysis

Python's AST and Radon measure lines of code, cyclomatic complexity, Halstead metrics and the maintainability index.

Code smells

Rule-based detectors find long functions, magic numbers, poor naming and duplicated code.

Machine learning

Random Forest models trained on a published Python code smell dataset predict Large Class and Long Method smells.

Quality gate

File scores combine into a LOW, MEDIUM or HIGH rating, and the project passes or fails the gate.

FAQ

 

What files can I upload?

A single .py file or a .zip archive. Inside a zip only .py files are analysed, and folders such as venv, .git and node_modules are skipped.

Is there a size limit?

Uploads can be up to 500 MB. Archives with more than 200 MB of source code are rejected.

What happens to my files?

They are analysed on the machine running this app and deleted as soon as the analysis finishes.

How is the risk score calculated?

It is a weighted score: 25% model-predicted smell probability, 25% maintainability, 15% complexity and 35% detected smell count. Below 0.33 is LOW, below 0.66 is MEDIUM, and anything higher is HIGH.
